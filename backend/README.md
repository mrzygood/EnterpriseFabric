## Backend

ASP.NET Core minimal API (`EnterpriseFabric.Api`).

### API Documentation

The OpenAPI document is served by the running API (Development environment only):

- http://localhost:5092/openapi/v1.json
- https://localhost:7039/openapi/v1.json

An interactive Scalar UI is available at (Development environment only):

- http://localhost:5092/scalar/v1
- https://localhost:7039/scalar/v1

### Running

```
dotnet run --project EnterpriseFabric.Api
```
